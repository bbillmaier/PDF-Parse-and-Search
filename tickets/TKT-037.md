# TKT-037 - Add search filters, suggestions, and quality regression coverage

**Epic:** [Epic H: Robust lightweight search](epics/EPIC-H.md)
**Milestone:** [M8: Robust lightweight search](milestones/M8.md)
**Labels:** `search`, `filters`, `autocomplete`, `e2e`, `performance`, `epic-h`, `m8`
**Dependency links:** [TKT-035](TKT-035.md), [TKT-036](TKT-036.md)
**Design link:** [docs/DESIGN.md section 21](../docs/DESIGN.md#21-search-quality-design)
**Backlog link:** [tickets/README.md](README.md)

**Goal:** Complete the robust search experience with useful filters, bounded suggestions, and regression evidence across real and synthetic collections.

**Dependencies:** TKT-035 and TKT-036

**Scope:**

- Add document, page/section, and semantic block-type filters to the API and UI.
- Add indexed prefix suggestions for document titles, section headings, and high-value technical terms.
- Debounce suggestions, require a minimum prefix, cap results, and cancel stale requests.
- Create a relevance fixture set covering phrase, operator, prefix, partial, technical, stemmed, synonym, typo, filter, and grouping behavior.
- Benchmark strict, phrase, prefix, fallback, and empty-result paths against real documents and deterministic thousands-document data.
- Record query strategy and score diagnostics in development mode.
- Update the AI-agent main-application guide with every schema, API, configuration, UI, and reindexing obligation introduced by TKT-030 through TKT-037.

**Out of scope:** Search analytics, personalized ranking, production load testing, extensions, embeddings, and AI answers.

**Acceptance criteria:**

- Filters compose safely with every supported query path.
- Suggestions never scan complete document bodies per keystroke.
- The relevance suite fixes expected top results and match strategies for representative queries.
- Synthetic thousands-document benchmarks record indexed plans and reproducible latency.
- Existing HTML/PDF navigation remains correct from grouped and filtered results.
- The main-app integration guide is sufficient for a clean-context dev agent to reproduce the feature boundaries.

**Verification:** API/UI filter and autocomplete tests, complete relevance suite, PostgreSQL plan checks, benchmark report, and clean-context guide review.
